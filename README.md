Interactive Space Station
A 3D space station project created using Three.js as part of my final-year Computer Graphics project at UNISA.

About the Project
The project features:
- A textured and illuminated 3D space station
- Rotating animation
- Earth, Moon and the Sun
- A surrounding star field
- Smaller spaceships orbiting the space station

Technologies Used
- HTML
- JavaScript
- Three.js

Project
This project was created as part of my university coursework while developing my skills in 3D graphics and web development.
